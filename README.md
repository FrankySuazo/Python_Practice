# Python Practice 🐍

A collection of Python exercises and small projects documenting my progress as I build a foundation in programming.

This repository brings my practice into one place, organized by topic. My focus is on understanding the logic, solving problems, and writing readable code.

## Topics

| Folder | What I practice |
|---|---|
| `fundamentals/` | Variables, data types, user input, operators, and string formatting |
| `conditionals/` | Comparisons, Boolean logic, and `if`, `elif`, and `else` statements |
| `loops/` | `for` and `while` loops, counters, and accumulators |
| `lists_and_dictionaries/` | Indexing, slicing, list methods, and dictionary keys and values |
| `functions/` | Parameters, return values, scope, and reusable logic |
| `mini_projects/` | Combining concepts into small, interactive programs |

## Practice Examples

- **Area Calculator:** Calculate the area of different shapes using a menu.
- **Rock, Paper, Scissors:** Practice conditionals, random choices, and input validation.
- **Number Guessing Game:** Use loops, comparisons, and limited attempts.
- **Lottery Number Generator:** Generate random numbers and store them in lists.
- **FizzBuzz:** Practice loops, divisibility, and conditional logic.
- **Stock Price Analysis:** Practice functions, list slicing, and finding minimum and maximum values.

## How to Run

Install Python 3, download or clone this repository, and open a terminal in the repository folder.

Run an exercise using its path:

```bash
python mini_projects/area_calculator.py
```

Replace the path with the file you want to run. Depending on your system, use `python3` instead of `python`.
